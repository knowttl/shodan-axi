# Shodan account access

Inspect Shodan account information.

- `shodan-axi info`
- `shodan-axi account profile`
- `shodan-axi --help`

Use `--json` for JSON output.
Configure a profile with `shodan-axi profile set <name> --env <variable>` or `--file <absolute-path>`; do not put a key on the command line.
