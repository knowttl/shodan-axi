# Shodan investigation

Inspect Shodan account, host and DNS information.

- `shodan-axi info`
- `shodan-axi host <ip>`
- `shodan-axi search <query> --help`

Use `--json` for JSON output.
Configure a profile with `shodan-axi profile set <name> --env <variable>` or `--file <absolute-path>`; do not put a key on the command line.
Credit-consuming reads require an exact operation grant and explicit budget.
